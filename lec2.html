    Lecture 1 ended with a problem

    Noisy answers can still leak a whole secret column. We saw two attacks, and we saw that the noise has to be around √n before they fail.

    But “noise of size E” is a recipe, not a promise. It doesn't say what an attacker can learn about one person.

    Lecture 2 gives the promise

    Differential privacy says: the output must look almost the same whether or not any one person's row is in the table. “Almost” is measured by a number, ε.

    To prove things we need a little probability first: expectation and variance.

    What this shows

    The server answers m subset-sum queries and splits a total budget ε equally: each gets ε/m, so each answer has Laplace noise of scale m/ε. Large ε means little noise, so the attacker rebuilds the column. Small ε means huge noise, so the attacker is guessing, but then the answers are also useless for the analyst. Privacy and accuracy pull in opposite directions.

    Cheat sheet

    Neighbouring tables D, D′ differ in one person's row.

    ε-differential privacy. A randomized mechanism M is ε-DP if for all neighbours D, D′ and every set S of outputs:

    Pr[ M(D) ∈ S ] ≤ eε · Pr[ M(D′) ∈ S ]

    Randomized response (keep the truth with probability p = eε/(1+eε), otherwise flip) is ε-DP: for n people the factors of everyone who didn't change cancel, and the one person who did gives a ratio Pr[y|x=0]/Pr[y|x=1] of eε or e−ε. The full proof is in chapter 5. Two fair coins give p = 3/4, ε = ln 3.

    Unbiased estimate from randomized response. q = Pr[y=1] = (1−p) + π(2p−1), so π̂ = (ȳ − (1−p)) / (2p−1) has E[π̂] = π and Var(π̂) = q(1−q) / (n(2p−1)²).

    Laplace mechanism. For a query f with sensitivity Δ = max |f(D) − f(D′)|, output f(D) + Lap(Δ/ε). Density ratio ≤ e|f(D)−f(D′)|/(Δ/ε) ≤ eε. Variance 2Δ²/ε².

    Composition. Series (same data): ε₁ + ε₂ + … . Parallel (disjoint data): max(ε₁, ε₂, …). Post-processing never weakens ε.

    How lecture 1 and 2 connect

    • Lecture 1: if each answer's noise is below about √n, an attacker rebuilds the data.
    • Lecture 2: randomized response and Laplace noise give a definition that survives any attacker, and composition tells you how fast the budget runs out.
    • The variance of a sum of n bits is ∝ n, so its spread is ∝ √n. That is the same √n.
