# Privacy-preserving data analysis, explained

Interactive companions to the lectures. Each page walks through the ideas step by step, with demos that run on their own and settings you can change.

**Live site:** https://babhero10.github.io/Privacy-preserving-Data-Analysis-ML/

- **Lecture 1:** reconstruction attacks. Exponential attack and the 4αn bound (with proof), the polynomial attack and the √n threshold.
- **Lecture 2:** differential privacy. Probability recap, the definition, randomized response, Laplace mechanism, composition, and a live private query server.

Plain HTML, CSS and JavaScript with no build step. To run locally: `python3 -m http.server` in this folder and open http://localhost:8000.
